# Homepage carousel images

Original AI-generated illustrative photographs, created with the built-in imagegen tool for this project. These are fictional scenes, not photographs of affiliated institutions or banks. No third-party stock images are used.

The generated PNGs were converted to 1920 × 1080 WebP at quality 82 with cwebp (resized from 1672 × 941). The three delivery assets total approximately 380 KB. Images contain no intended readable copy; all hero text remains accessible HTML.

- `institutional-security.webp`: campus and secure document folio.
- `fdr-verification.webp`: laptop verification interface and certificate.
- `banking-assurance.webp`: banking office, records and verification tablet.
